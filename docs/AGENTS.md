# AGENTS.md: docs/

`mapping.md`: the reference for the adapter. It lists every operation with its provider endpoints,
every webhook and ledger entry with its event, the currency and network mapping, the KYC tiers, SCA,
cards, and the gaps.

- A change in any mapping updates this file in the same commit.
- Keep the gaps section honest: if a scenario cannot run in the sandbox, say so here and in the README.
